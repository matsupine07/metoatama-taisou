プライバシーについて

「めとあたまの たいそう」は、つかう人の 名前・メールアドレス・電話番号などを あつめません。ログイン（アカウント）も ありません。

この端末に のこるもの

せっていで 入れた「おなまえ」・もじの おおきさ・おと・むずかしさ・トレーニングを した日の 記録は、お使いの ブラウザの localStorage（名前は kinokaifuku_v1）に だけ のこります。この端末の外へは 送りません。ネットが なくても ひらけるように、アプリの ファイルも 端末に 保存します（サービスワーカー）。

消すときは、ブラウザの せっていで「サイトのデータ」を 消してください。

アクセス解析

アクセス解析は Cloudflare Web Analytics を使っています（2026年11月25日から）。ページを ひらくと、Cloudflare の 小さな プログラム（static.cloudflareinsights.com から 届きます）が、ひらいた ページの アドレス・どこから 来たか（前の ページの アドレス）・表示の 速さを、このページの アドレス（/cdn-cgi/rum）を通して Cloudflare に 送ります。クッキーや localStorage は 使わず、端末を 見分ける 印も 作りません。作者に 見えるのは、見られた 回数・どこから 来たか・国・ブラウザや 端末の 種類などの 集計だけです。このプログラムは、13.pineapp.jp を通して ひらいたときに Cloudflare が 自動で 入れるもので、アプリの ファイルには 入っていません。

広告は 入れていません。

配信の しくみ

このアプリは Cloudflare の Cloudflare Pages で 配信しています。住所は https://13.pineapp.jp/ です（2026年11月25日から。前の住所 https://matsupine07.github.io/metoatama-taisou/ を ひらくと、こちらへ 移ります）。ページを ひらくとき、一般的な ウェブ配信と 同じく、配信する側が IP アドレス・ブラウザの 種類・ひらいた 日時・ひらいた アドレスなどを 受け取る ことが あります。作者は これらで 人を 見分ける ことは しません。
